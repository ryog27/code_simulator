書き方（共通テスト用プログラム表記）

    

      
代入x = 10　Data = [3, 8, 2]　a = 1, b = 2

      
増やす・減らすx を 1 増やす　x を 2 減らす

      
すべての要素Hindo のすべての要素を 0 にする

      
表示表示する("合計は", goukei)（並べた値をつなげて1行に表示）

      
計算+ - * /　÷（商・整数）　%（余り）　**（べき乗）

      
比較==　!=　<　>　<=　>=（≠ ≦ ≧ も可）

配列Data[i]（添字は 0 から）　Hyo[i][j] または Hyo[i, j]

      
関数要素数(Data)　整数(x)　切り上げ(x)　四捨五入(x)　絶対値(x)　平方根(x)　乱数()　乱数(1, 6)　二進(x)　文字列(x)　数値(s)

      
コメント# ここから行の終わりまで

    

    
条件分岐


もし x < 3 ならば:
│ 表示する("小さい")
そうでなくもし x < 6 ならば:
│ 表示する("中くらい")
そうでなければ:
└ 表示する("大きい")

    
繰り返し


i を 0 から 9 まで 1 ずつ増やしながら繰り返す:
└ goukei = goukei + i

x > 0 の間繰り返す:
└ x = x ÷ 2

繰り返す:
└ n = n + 1
を, n * n > 50 になるまで実行する

    
字下げには │ └ と空白のどちらも使えます。同じかたまりの行は、行の始めの幅をそろえてください（│ 1つと空白1つは同じ幅）。
