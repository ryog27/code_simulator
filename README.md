# プログラム ステップ実行

共通テスト用プログラム表記（DNCL）で書いたプログラムを1行ずつ実行し、どの行で何が起きて変数や配列がどう変わったかを見せる教材。

## 使い方

`index.html` をブラウザで開く（サーバーは要らない）。

- 左にプログラムを書き、「▶ 実行してみる」（Ctrl+Enter）
- 「次へ ▶」「◀ 戻る」で1手順ずつ動かす。キーボードでは → ← スペース、Home／End、P で自動再生、Esc で編集に戻る
- コードの行をクリックすると、その行を次に実行する手順まで進む
- 「トレース表」タブに、変数が変わった手順を表にして出す。行をクリックするとその手順へ飛ぶ
- 「リンクをコピー」で、今のプログラムを開くURLを作る（プログラムはURLの `#code=` に入る）
- 書き方の一覧は画面右上の「書き方」

## ファイル

| ファイル | 中身 |
|---|---|
| `index.html` | 画面 |
| `css/style.css` | 見た目 |
| `js/dncl.js` | DNCL の解析と実行。全手順の記録（変数・出力・読み書きした場所）を返す |
| `js/app.js` | 記録を前後に動かして表示する |
| `js/samples.js` | 例題 |

## 公開（GitHub Pages）

ビルドは要らない。リポジトリに push し、GitHub の Settings → Pages で「Deploy from a branch」→ `main` / `/ (root)` を選ぶ。
